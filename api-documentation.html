REST API Reference

ResearchCollab API Documentation

This page documents the backend endpoints exposed by the server for authentication, projects, applications, messaging, recommendations, storage, and more.

Base URL: http://localhost:8080 (or your deployed host)

Authentication

GET/api/hi
Health check endpoint.
Public
POST/api/register
Create a new user account.
Public 
{
  "username": "student1",
  "password": "secret123",
  "email": "student@example.com",
  "name": "Jane Doe",
  "role": "student"
}
POST/api/login
Authenticate a user and create a session.
Public 
{
  "username": "student1",
  "password": "secret123"
}
POST/api/logout
Log out the current user.
Authenticated
GET/api/user
Fetch the authenticated user profile.
Authenticated

Projects

GET/api/projects
List projects. Query parameters: status, owner.
Public
GET/api/projects/:id
Fetch a specific project and its related applications.
Public
POST/api/projects
Create a new project. Requires ownership and authentication.
Authenticated 
{
  "title": "AI Research Project",
  "description": "Investigating LLM-based workflows",
  "requiredSkills": ["Python", "NLP"],
  "compensation": 500,
  "timeline": "Summer 2026",
  "status": "active",
  "remote": true,
  "location": "Remote"
}
PUT/api/projects/:id
Update an existing project. Only the owner may edit it.
Authenticated
DELETE/api/projects/:id
Delete a project. Fails if the project already has applications.
Authenticated

Opportunities

GET/api/opportunities
List opportunities. Query parameters: studentId, status.
Public
GET/api/opportunities/:id
Fetch one opportunity by ID.
Public
POST/api/opportunities
Create an opportunity for the authenticated student.
Authenticated 
{
  "title": "Research Assistant",
  "description": "Looking for a summer placement",
  "skills": ["Python", "Data Science"],
  "interests": ["ML", "Healthcare"],
  "availableHours": 20,
  "preferredCompensation": 1000,
  "availability": "Summer 2026",
  "remote": true,
  "preferredLocation": "Remote"
}
PUT/api/opportunities/:id
Update an opportunity. Only the owner may edit it.
Authenticated
DELETE/api/opportunities/:id
Delete an opportunity. Only the owner may delete it.
Authenticated

Applications

GET/api/applications
Get applications for the current user, or received applications for project owners. Query parameters: projectId, type=received.
Authenticated
POST/api/applications
Submit a new application to a project.
Authenticated 
{
  "projectId": "",
  "coverLetter": "I am excited to contribute to this project.",
  "proposalUrl": "https://example.com/proposal.pdf",
  "deadline": "2026-08-30"
}
PUT/api/applications/:id/status
Update application status to submitted, under_review, approved, or rejected.
Authenticated 
{
  "status": "approved",
  "reviewNotes": "Strong fit for the project"
}
PUT/api/applications/:id
Update application details. Only the project owner may update it.
Authenticated
GET/api/applications/:id/comments
Fetch comments for an application. Accessible to the applicant or project owner.
Authenticated
POST/api/applications/:id/comments
Create a new application comment. Internal comments are only allowed by the project owner.
Authenticated 
{
  "content": "Looking forward to working together",
  "isInternal": false
}

Embeddings and Object Storage

POST/api/embeddings/update-profile
Refresh the authenticated user's profile embedding.
Authenticated
POST/api/embeddings/update-project/:id
Refresh the embedding for a project owned by the current user.
Authenticated
POST/api/objects/upload
Get an upload URL for object storage.
Public
GET/objects/:objectPath(*)
Serve private objects such as CVs and uploaded files.
Public
PUT/api/users/cv
Update the authenticated user's CV URL.
Authenticated 
{
  "cvUrl": "/objects/user-cv.pdf"
}
PUT/api/projects/:id/flyer
Update a project's flyer URL. Only the owner may do this.
Authenticated 
{
  "flyerUrl": "/objects/project-flyer.png"
}

GET/api/chats/:id/messages
